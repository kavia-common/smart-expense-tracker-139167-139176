# Smart Expense Tracker - Ocean Professional (Frontend)

A bold, dark-themed React app with Supabase integration for:
- Auth (magic link)
- Expense and Category management with realtime updates
- Receipt uploads via Supabase Storage
- Dashboard and Insights (Recharts)

Environment:
- Set REACT_APP_SUPABASE_URL and REACT_APP_SUPABASE_KEY in .env

Run:
- npm install
- npm start

See more in src/README_APP.md and assets/supabase.md.
